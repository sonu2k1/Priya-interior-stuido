# 🏠 Priya Interior Studio

A premium, modern landing page for **Priya Interior Studio** — an interior design firm. Built with React and Vite for a fast, responsive, and visually stunning experience.

## ✨ Features

- **Hero Section** with multi-step price estimate form
- **Process Cards** showcasing the workflow
- **A to Z Interior Solutions** with interactive tabs
- **Guarantee Banner** & Happy Customers section
- **Trending Designs** gallery
- **Our Offerings** with service cards
- **How Do We Work?** section with CTA
- **Footer** with contact info & social links
- **Scroll to Top** button
- Fully responsive across all devices

## 🛠️ Tech Stack

- **React 19** — UI library
- **Vite** — Build tool with HMR
- **Vanilla CSS** — Custom styling with CSS variables
- **Google Fonts** — Playfair Display & Inter

## 🚀 Getting Started — Run Locally

### Prerequisites

Make sure you have the following installed:

- **Node.js** (v18 or higher) — [Download](https://nodejs.org/)
- **Git** — [Download](https://git-scm.com/)

### 1. Clone the repository

```bash
git clone https://github.com/sonu2k1/Priya-interior-stuido.git
```

### 2. Navigate to the project folder

```bash
cd Priya-interior-stuido
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The app will be running at **http://localhost:5173** 🎉

### 5. Build for production (optional)

```bash
npm run build
```

### 6. Preview the production build (optional)

```bash
npm run preview
```
